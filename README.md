# Hi, I'm Joshua Dowd

Computer Science student at Chapman University in Orange, CA. I gravitate toward problems where the computer has to make a decision: chess engines, self-play agents for board games, and tools that turn messy inputs (video, unlabeled images, scraped hackathon listings) into something a person can act on.

[Archangel](https://github.com/JoshuaDowdCS/Archangel), my chess engine, is the long-running project. It is paused at the moment; when I pick it back up, the next step is quiescence search, so the evaluation follows capture sequences to the end instead of stopping mid-exchange.

| [JNKS](https://github.com/nathsmith-cs/JNKS) | Basketball shooting-form coach: YOLOv8 ball tracking and MediaPipe pose, scored against pro reference shots with Gemini vision and spoken feedback. | [Chapman IEEE](https://github.com/JoshuaDowdCS/chapman-ieee) | Website for Chapman University's IEEE Student Branch, with a password-protected admin page so officers can edit content without touching code. [Live site](https://chapman-ieee.vercel.app) | Astro, TypeScript |
